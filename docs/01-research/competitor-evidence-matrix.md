## 1. 使用规则

- 66 个 ID 是研究、产品、体验和工程之间的稳定主键，不是功能数量上限。发现新的公开事实时允许追加 ID，不能为维持数字而覆盖证据。
- `confirmed` 是 iOS 当前公开页面、元数据、正文或截图直接支持；`cross-source` 是 Android 渠道、官方法律文本，或只能证明数据处理/运营用途而不能证明对应 UI 的 iOS App 隐私标签支持；`pending` 只是一项公开待验证问题。
- “Nuttie 处置”可以不同于竞品做法。`Nuttie-required` 表示本地闭环所需，不等于竞品已确认。
- 截图 S06 是健康评分/微量营养/风险/益处页面，不是条码结果页。条码结果的具体字段和布局不得写成截图事实。
- 除 `ACC-05` 能确认免费下载、`ACC-04` 能交叉确认订阅/IAP 存在外，公开资料不能确定具体免费/会员门槛。
