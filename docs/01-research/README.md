# 竞品研究索引

本目录冻结 G2 阶段可复核的竞品证据。唯一竞品是上海咪咪猪发布的 iOS 应用“自律茄子”，App Store ID 为 `6502774426`。

## 阅读顺序

1. [来源与证据说明](./source-and-evidence.md)：来源白名单、证据等级和使用限制。
2. [66 项细粒度证据矩阵](./competitor-evidence-matrix.md)：公开证据能支持的最小事实单元。
3. [24 类能力地图](./capability-map.md)：把 66 项事实聚合为产品能力，不增加事实。
4. [公开缺口机会清单](./public-evidence-gaps.md)：公开资料不能证明的九组问题，只能用于验证和机会评估。

## 冻结规则

- 研究截止日期：2026-07-31。
- `confirmed` 仅用于 iOS App Store 当前文案、Apple 公开元数据或四张 iPhone 截图可直接支持的事实。
- `cross-source` 用于 Android 商店、官方隐私政策、官方用户协议，或只能证明数据处理/运营用途而不能证明对应 UI 的 iOS App 隐私标签事实。
- `pending` 表示公开资料不足，不能写入确定需求或宣称为竞品功能。
- 当前行级统计为 37 `confirmed`、24 `cross-source`、5 `pending`；五条 `pending` 是 `LOG-08`、`LOG-09`、`AI-06`、`DATA-07`、`DATA-08`。
- “所有功能”的项目验收口径由 `D-001` 定义为“所有公开可验证功能”，不是无法访问的真机或会员态全量。
- 专注计时、番茄钟、应用锁/锁机、社区和排行榜均无指定竞品证据，不纳入对标范围。
- 用户协议中的 UGC、广告等通用条款不能单独证明当前产品存在对应 UI。
