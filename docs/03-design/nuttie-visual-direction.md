# Nuttie 视觉方向与 Figma 导入合同

状态：`CONCEPT / FIGMA_MCP_PENDING`

本文件登记 Nuttie 的第一版原创视觉方向。它是设计探索和 Figma 导入合同，不是 Owner 对 D-038 的最终选择，也不授权创建 React Native 正式页面。正式视觉方向仍需在聊天内原生选择卡中由 Owner 确认。

## 核心概念

Nuttie 的视觉主角是“会陪用户一起积累的小栗子”。栗子不是静态贴纸，而是状态反馈组件：它随着记录、连续行动和成长趋势改变姿态；失败或空状态不惩罚用户，只给出可恢复的下一小步。

品牌文案：

- 中文：积“栗”前行，“立”见更好的自己。
- English：Small steps, solid growth.

## 角色状态映射

| 角色变体 | 业务状态 | 反馈语气 | 允许出现的位置 |
| --- | --- | --- | --- |
| `mascot-home` | 今日总览、尚未完成目标 | 轻声问候、给出下一步 | 首页首屏、空白今日状态 |
| `mascot-meal` | 记录餐食、等待份量确认 | 陪伴核对，不替用户做决定 | 餐食录入、AI 预览确认 |
| `mascot-growth` | 趋势页、连续记录或目标进展 | 强调小步增长，不比较他人 | 趋势页、周/月总结 |
| `mascot-streak` | 连续行动达成里程碑 | 庆祝行为，不制造焦虑 | 成就反馈、连续记录完成 |

角色状态不能用于遮挡错误信息、替代可访问文本或暗示健康结论。营养和健康数据必须仍以文本和结构化数值呈现。

视觉资产契约由 `tools/visual-kit-check.mjs` 固定，并由 `tools/visual-kit-check.test.mjs` 验证：三张核心画面、四个角色变体、九个辅助插画、三个可访问角色实例、三个具名底部导航、44px 最小触控高度、进度与趋势的文本语义、无远程 HTML 资源，以及仅绑定 `127.0.0.1` 的预览服务器。

## Figma 导入顺序

真实 Figma MCP 连接可用后，按以下顺序创建文件和页面：

1. `00 Visual Tokens`：颜色、圆角、间距和文字层级候选。
2. `01 Mascot Components`：导入两个 SVG 资产板，建立四个角色状态变体和九个辅助插画组件，并标注状态映射与装饰/语义边界。
3. `02 Core Screens`：导入三张手机画面，保持 390 × 844 画板、角色状态、辅助插画、44pt 触控目标和图表文字摘要。
4. `03 Prototype Notes`：记录本地优先、AI 主动确认发送和待 Owner 决策边界。

导入后必须检查：字体加载、中文不截断、角色 SVG 不为空、窄屏不横向溢出、状态组件有可访问文本，并为每个页面保留截图证据。MCP 未连接前不得写入“已创建 Figma 文件”或伪造 Figma 链接。

## Owner 评审边界

本方向需要单独的聊天内原生选择卡确认：

- 是否接受“栗子作为状态反馈角色”的方向；
- 是否接受候选色彩与暖纸底色；
- 是否接受四种角色状态和三张核心画面作为下一轮视觉基线。

在 Owner 选择前，D-038 仍保持候选状态，视觉资产只可用于研究、讨论和原型验证。
