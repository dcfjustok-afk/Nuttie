## 1. 结论

原 `D040-RESEARCH-002` 的“中国宏量标准证据缺口”现可关闭到 `CURRENT_STANDARD_EVIDENCE_COMPLETE`：

- 国家卫健委提供 `WS/T 578.1-2017` 官方页面和 12 页 PDF；全国标准信息公共服务平台在 2026-08-20 核验时将其标为“卫生、推荐性、现行”。
- 标准第 5.1 条给出成年人膳食产能营养素供能百分比：碳水化合物 `50%–65%`、脂肪 `20%–30%`、蛋白质 `10%–15%`。
- 标准附录 A 给出蛋白质、碳水化合物、脂肪的折算系数 `4/4/9 kcal/g`，因此中国参考路径无需再只依赖美国食品标签规则解释该换算。
- 三个区间不能自动生成唯一 `100%` 三元组：下端合计 `80%`，上端合计 `110%`。它们只能作为分别标注的参考范围，不是默认目标、个体处方或减重最优比例。
- 2025 年已有该标准修订征求意见稿，但没有检索到已发布替代标准；征求意见稿不能作为现行值。每个 Release 和最长 90 天必须重新检查现行状态，替代标准发布或状态变化时立即失效。

因此，D-063 的“中国现行标准参考带”选项已具备证据输入，但 D-063 本身仍为 `NOT_OWNER_READY`：具名健康评审、选择卡自审/独立复核和 Owner 评审都未发生。

## 3. 标准原义与产品映射

`WS/T 578.1-2017` 第 1 章说明其规定中国居民膳食能量、蛋白质、脂类和碳水化合物参考摄入量，适用于中国居民健康人群或个体的膳食摄入评价和膳食指导。第 3.1.4 条把 AMDR 定义为兼顾预防产能营养素缺乏和降低慢性病风险的每日摄入量下限和上限。

| 标准项 | 现行成人值 | Nuttie 可表达 | Nuttie 不得表达 |
| --- | --- | --- | --- |
| 碳水化合物 | `50%–65% E` | “WS/T 578.1-2017 健康成人参考范围” | 默认碳水目标、减重最优范围、个人安全上下限 |
| 脂肪 | `20%–30% E` | 同上 | 超出即不健康、自动告警或自动纠正 |
| 蛋白质 | `10%–15% E` | 同上 | 个体蛋白质处方、运动/减脂最优剂量 |

`% E` 表示占总能量百分比。若 D-063 以后选择参考带，界面必须：

1. 同时显示标准名或可进入的来源说明、标准号和“健康成人参考范围”；
2. 把三项分别显示为范围，不选择区间中点、端点或自动凑出 `100%`；
3. 不生成达标环、红绿灯、风险分、自动纠正、减重建议或“超标”诊断语言；
4. 不把参考带保存成用户 `GoalVersion`，除非用户以后通过另一个明确的自定义目标决定创建自己的 `100%` 三元组；
5. 仅对满足 D-054 和特殊人群保护条件的健康成人候选显示。标准表的成人行从 `18～` 开始，但 Nuttie 可以选择更严格的 19+ 产品门槛，不得反向扩大已选能量模型的人群边界；
6. 在慢性病/用药、孕哺期、未成年人或进食障碍风险等当前失败关闭场景中，不把一般成人范围当个体建议。

标准适用于健康个体的膳食评价/指导，不等于 Nuttie 获得医疗资质，也不替代 [中国大陆支持文案与健康评审治理输入包](d040-china-support-health-review-input.md) 要求的具名健康评审。

## 4. 组合和换算合同

### 4.1 参考范围不产生默认三元组

```text
carbohydrateRange = [50, 65]
fatRange = [20, 30]
proteinRange = [10, 15]

minimumEndpointSum = 80
maximumEndpointSum = 110
defaultTriplet = none
```

任何实际三元组若要作为用户目标，仍必须满足 D-070 以后批准的输入合同，例如三项完整设置时合计 `100%`。落在三个独立参考范围内只是可能的校验条件，不足以从范围推导唯一答案。

### 4.2 `4/4/9` 只负责单位换算

附录 A 表 A.1 给出：

```text
protein:       17 kJ/g (4 kcal/g)
carbohydrate:  17 kJ/g (4 kcal/g)
fat:           37 kJ/g (9 kcal/g)
dietaryFiber:   8 kJ/g (2 kcal/g)
```

D-040 当前只把 P/C/F 的 `4/4/9` 用于已选择能量和已确认比例之间的换算：

```text
protein_g = energy_kcal * protein_percent / 100 / 4
carbohydrate_g = energy_kcal * carbohydrate_percent / 100 / 4
fat_g = energy_kcal * fat_percent / 100 / 9
```

该公式不选择能量、不选择比例、不决定舍入，也不要求日记中食品标称能量必须严格等于三项回算值。膳食纤维 `2 kcal/g` 只记录为标准事实，D-013 当前七字段和 D-040 P/C/F 目标都不得未经另案决定把它加入或重复加入能量回算。

## 5. 版本、失效与离线边界

可发布的中国参考带证据必须记录：

```text
standardId = WS/T 578.1-2017
standardTitle
standardStatus = CURRENT_RECOMMENDED_INDUSTRY_STANDARD
officialPageUrl
officialPdfUrl
statusRegistryUrl
sourceCheckedAt
reviewDueAt
healthReviewerName
healthApprovedAt
supersedesEvidenceVersion
```

失败关闭规则：

- 每个 Release 候选同时复查国家卫健委发布页/PDF和全国标准信息公共服务平台状态；距 `sourceCheckedAt` 超过 90 天不得发布“中国现行标准参考带”。
- 正式替代标准发布、2017 版不再为现行、标准页/PDF无法匹配、范围/适用人群变化或具名健康评审提出异议时，当前证据立即标记 `STALE/BLOCKED`。
- 2025 征求意见稿只触发 revision watch；没有正式标准号、发布和实施链时不得更新产品值。
- Release 失败关闭时仍保留无目标日记和用户手工记录；不得回退到 NASEM AMDR 并继续标成“中国标准”。
- 运行时不联网检查标准，不下载远程规则，不使用远程开关修改已安装版本的目标。标准状态核验属于发布治理。
- 新标准不回算历史 `GoalVersion` 或日记。若用户以后主动采用新版本，必须创建带新标准 ID 的候选/版本并明确确认。

90 天是 Nuttie 的候选发布治理上限，不是 `WS/T 578.1-2017` 规定的临床复核周期。
