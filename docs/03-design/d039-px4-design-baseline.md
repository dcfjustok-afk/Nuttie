## 1. 冻结范围

D-039 只冻结“从添加餐食进入具体录入方式前”的首层组织，不改变 D-038 四目的地导航，不选择页面路由库、持久化结构、Provider、媒体保留或正式视觉组件。

首层使用以下稳定设计 ID：

| 稳定 ID | 层级 | 规格 |
| --- | --- | --- |
| `D039-ENTRY` | 页面 | 添加餐食首层；从日记的情境新增进入 |
| `D039-LOCAL-SEARCH` | 首要 | 本地搜索输入；同时查询已安装数据包与用户食品并显示来源 |
| `D039-RECENT` | 首要 | 最近使用列表；为空时不伪造条目，也不自动改成收藏或联网推荐 |
| `D039-SCAN` | 辅助 | 扫描条码；与 AI 同级，不高于本地路径，仅在用户触发后解释并请求相机权限 |
| `D039-AI` | 辅助 | AI 辅助；与扫描同级，未配置或 D-053 未准入时保持本地降级，不发送任何内容 |
| `D039-CREATE-FOOD` | 恢复 | 创建用户食品；搜索无结果、条码未命中或用户主动选择时可达 |
| `D039-REVIEW-SAVE` | 下游共用 | 所有成功候选进入统一检查与保存；D-039 不决定其字段、事务或持久化实现 |

## 2. 首层顺序与层级

`D039-ENTRY` 的阅读、键盘和 VoiceOver 逻辑顺序固定为：

1. 页面标题与当前日期/餐次上下文；
2. `D039-LOCAL-SEARCH`；
3. `D039-RECENT` 标题及已有条目，或明确的空态；
4. “其他方式”分组中的 `D039-SCAN`、`D039-AI`；二者同级，不用尺寸、默认焦点或推荐徽标制造优先级；
5. `D039-CREATE-FOOD`。

方案 B 的“记住上次方式并作为默认落点”和方案 C 的“六种方式全部首层平铺”均不进入基线。AI 图片、相册、文字和营养标签是进入 `D039-AI` 后的次级选择，不在首层与本地搜索争夺主层级。

## 3. 返回与状态合同

- 从搜索结果、最近条目、扫码、AI 或创建食品返回时，恢复到原触发控件；控件已消失时回到 `D039-ENTRY` 标题。
- 从 `D039-ENTRY` 返回时回到发起添加餐食的日记上下文；不得因进入 AI 或扫码而改变默认新增方式。
- 切换或退出任何辅助路径都不构成发送同意、保存同意或永久偏好。
- 本地搜索无结果使用 `ST-EMPTY-05`；条码未命中使用 `ST-EMPTY-06`；AI 未配置使用 `ST-EMPTY-07`。
- 相机拒绝/受限时必须提供输入条码、搜索、创建食品、可用的系统媒体选择和系统设置；系统媒体选择取消或失败时仍保留本地路径。
- AI 取消、失败或 D-053 阻断时，候选和日记写入均为 0；本地搜索、最近使用和创建食品继续可用。
- 表单或保存失败保留用户草稿并聚焦第一个可修正字段；营养缺失与数值 0 不得混同。

## 4. 无障碍与布局

- 所有交互目标至少 44 x 44 pt；标签持久可见，错误通过可访问描述与字段关联。
- Dynamic Type 下允许文本换行，不能裁掉搜索、最近、扫描、AI 或创建食品任一入口。
- 普通文本对比度至少 4.5:1，大文本至少 3:1；状态不得只靠颜色表达。
- 遵守 Reduce Motion；焦点恢复和状态公布不依赖动画。
- iPhone 竖屏 320、375、430 宽不得出现根级横向溢出；本基线不自动扩展为 iPad 或横屏承诺。
- 初始焦点进入页面标题，不自动落到扫描、AI 或发送动作；系统拒绝后焦点回到解释和替代动作区域。
