| 非目标 | 医疗诊断、治疗建议、自动转诊、紧急救援、正式 UI 文案、Owner 选择或实现授权 |

## 1. 结论

本输入包把中国大陆首发所需的支持称谓、资源用途、候选文案和评审责任拆成可审查合同，但不假装完成了健康领域批准。

当前可以固定的边界是：

- 一般支持统一称为“了解你健康情况的医生或医疗卫生专业人员”；需要更具体的体重管理服务时，可提示用户联系当地医疗机构的健康体重管理门诊或相关科室。产品不把未核验的社会职业称谓写成医疗资质。
- `12356` 只描述为全国统一心理援助热线，用于心理健康教育、心理咨询、心理疏导和心理危机干预；不得把它描述为医疗急救、自动转诊或保证接通的服务。
- `120` 只用于急危重症或紧急医疗救援；Nuttie 必须同时声明自己不提供紧急救援。
- 慢性病、用药、进食障碍风险或“不确定”回答都不能让 App 诊断、排除风险或自动调整能量；触发保护条件时只停止相关自动数字，继续提供手工目标或无目标日记。
- 所有文案必须随 App 离线携带。来源复核是发布治理，不依赖运行时联网，也不授权定位、通讯录、分析上报或自动拨号。

中国大陆支持文案草案已经具备逐条评审条件；但具名健康评审人、资质证据和批准记录都不存在，因此 D-068/D-069 仍为 `NOT_OWNER_READY`，PX-0 继续开放。

## 4. 候选简中文案

以下内容是待健康评审的语义基线，不是可直接发布的最终文案。语气、长度和页面位置可以调整，但不得删除停止推导、非诊断、可继续记录和资源用途边界。

### `COPY-D040-ND-01` 一般边界

> Nuttie 用于本地记录和一般性估算，不用于诊断、治疗或紧急救援。

### `COPY-D040-ND-02` 慢性病或用药回答“有”

> 你的健康情况或用药可能影响体重或能量需要。Nuttie 不会据此判断疾病或自动调整目标，本次自动估算已暂停。你仍可使用无目标日记，或录入由了解你健康情况的医生或医疗卫生专业人员给出的手工目标。

### `COPY-D040-ND-03` 慢性病或用药回答“不确定”

> 如果你不确定健康情况或用药是否会影响体重或能量需要，自动估算会先暂停。你可以继续无目标记录，并向了解你健康情况的医生或医疗卫生专业人员确认。

### `COPY-D040-ND-04` 主动自述进食障碍风险

> Nuttie 不会根据这道问题诊断或排除进食障碍。为避免强化减重数字，自动减重和宏量目标已暂停；你仍可使用无目标日记。需要心理支持时，可拨打全国统一心理援助热线 12356。

`12356` 后必须保留“心理援助”用途标签，不得单独显示为紧急医疗动作。是否需要更具体的进食障碍就医文案，必须由具名健康评审人另行批准；仓库当前没有足够中国大陆证据支持更具体路径。

### `COPY-D040-ND-05` 急危重症

> 如有急危重症或需要紧急医疗救援，请立即拨打 120。Nuttie 不提供紧急救援。

产品不得自行推断“急危重症”；这段文案只能出现在用户主动查看的安全说明，或由以后经健康评审批准的明确触发条件调用。

### `COPY-D040-ND-06` 估算不确定性

> 这是基于群体方程的估算，不是对你个人需要量的精确测量。输入和活动分类变化会影响结果；群体误差指标不能理解为你的个人上下限。

只有 D-069 以后选择展示具体群体指标时，才能追加已核验模型对应的名称、样本和数值；不得把 NASEM 的 RMSE/MAPE 转成个人预测区间。

## 5. 触发行为与失败关闭

| 场景 | 自动能量/减重/宏量 | 仍允许 | 资源行为 | 写入边界 |
| --- | --- | --- | --- | --- |
| 慢性病或用药=`有` | 暂停相关自动估算 | 无目标日记；用户明确录入专业人员给出的手工目标 | 展示 `TERM-D040-01/02` | 失败或取消时 Profile/Goal 写入均为 0 |
| 慢性病或用药=`不确定` | 与“有”同样失败关闭 | 无目标日记 | 展示 `TERM-D040-01/02` | 不把“不确定”改写为疾病事实 |
| 主动自述进食障碍风险 | 停止自动减重和宏量目标 | 无目标日记 | 可展示 `TERM-D040-03`，但不取代紧急医疗说明 | 不保存诊断标签；具体保存策略仍待 D-068/数据决定 |
| 用户主动查看紧急说明 | 不改变业务状态 | 退出页面、继续手工/无目标路径 | 展示 `TERM-D040-04` | 不读取位置、不创建“已救援”记录 |
| 资源来源过期或未复核 | 不因此开启任何自动公式 | 通用非诊断说明和无目标记录 | 新 Release 失败关闭；已安装版本不运行远程开关 | 不联网拉取替换文案 |

`12356` 与 `120` 必须是两个语义独立的动作。任何实现都不得因为展示、复制或拨号动作成功，就记录为咨询已完成、医疗服务已获得或风险已解除。

## 6. 健康评审责任矩阵

| 角色 | 最低责任 | 当前状态 | 不得代替 |

| `ProductContentOwner` | 维护 copy ID、触发条件、来源链接和变更记录 | PM 可准备草案，未批准发布 | 健康专业判断 |
| `ChinaQualifiedHealthReviewer` | 提供具名身份和当前资质证据；审查非诊断含义、停止推导、专业称谓、12356/120 用途和风险遗漏 | `UNASSIGNED` | Owner 产品选择、法务意见、QA 执行 |

健康评审人至少必须能证明：姓名、审查时有效的专业资质或执业依据、与体重/营养/相关健康风险审查的胜任范围、利益冲突披露和批准时间。仓库不得只写角色名或 Agent ID 就宣称责任人已到位。

## 7. 复核周期与失效条件

每条可发布文案记录必须保存：

```text
copyId
copyVersion
locale = zh-Hans-CN
sourceUrls[]
sourceCheckedAt
healthReviewerName
healthReviewerQualificationRef
healthApprovedAt
qaApprovedAt
reviewDueAt
supersedesCopyVersion
```

治理周期：

1. 首次进入实现前必须完成具名健康评审和 Content QA；缺任一签署即失败关闭。
2. 每个 Release 候选都重新核对来源；距 `sourceCheckedAt` 超过 90 天不得发布。
3. 国家卫健委或其他主管来源变化、号码/服务可用性变化、健康评审发现、用户安全事件/投诉、公式/触发条件/文案语义变化时立即失效，不等待 90 天。
4. 文字样式或无语义排版调整仍需 QA；任何改变号码、用途、停止条件、专业称谓或允许行为的调整都必须重新健康评审。
5. 复核失效只阻断新 Release，不通过远程网络删除已安装 App 的离线支持文案；修复路径由后续发布治理决定。

90 天是 Nuttie 的候选内容治理上限，不是上述一手来源规定的临床周期，也不代表资源只在 90 天内有效。
