# Nuttie 产品范围基线

状态：`G2_DRAFT_FOR_REVIEW`  
基线日期：2026-07-31

## 1. 产品定义

- 中文名：栗子自律
- 英文名：Nuttie
- 中文标语：积“栗”前行，“立”见更好的自己。
- 英文标语：Small steps, solid growth.
- 目标平台：iOS 17+，首发简体中文（D-011、D-016）。
- 使用对象：发起人本人和朋友；不建设业务服务器。
- 核心承诺：饮食、营养、体重、饮水、运动、提醒、洞察和数据管理在设备本地完成；只有用户主动使用 AI 时才访问其自行配置的 OpenAI-compatible HTTPS Provider。

Nuttie 不是医疗器械，不提供诊断、治疗方案或营养处方。

## 2. 目标与非目标

### 2.1 产品目标

1. 覆盖自律茄子全部公开可验证的 F01-F24 能力，并对每类给出明确去向。
2. 在无账号、无业务服务器、飞行模式下完成核心记录、统计、查询和数据管理。
3. 用可检查、可修改、可删除的本地数据取代黑箱账号、云同步和会员权益。
4. 允许用户自带 AI Provider，但任何 AI 失败不破坏本地核心流程。
5. 对营养来源、缺失值、估算值、AI 候选和用户确认值保持可追踪。
6. 通过小批 Owner 决策逐步确定交互和技术候选，不把计划当成批准。

### 2.2 明确非目标

- 不建设登录、会员、支付、广告、排行榜、社区、远程 Push 或业务后台。
- 不实现无证据的专注计时、番茄钟、应用锁或锁机。
- 不集成遥测、第三方分析、崩溃上传、CloudKit、EAS OTA 或远程配置。
- 不承诺离线条码覆盖所有中国商品，不承诺 AI 准确率或医疗效果。
- 不把 Files 导出位置描述为“永不进入云端”；位置由用户和 iOS 文件提供方决定。
- 不默认提供明文 JSON/CSV 健康数据导出；D-035 未批准前仅有 D-006 的加密备份。

## 5. 本地优先不可变约束

### 5.1 网络

- 所有本地能力必须在零网络条件下工作。
- 只有 `AITransport` 可以发起业务网络请求；食品搜索、条码查询、统计、提醒、备份和数据包导入不得联网。
- 无遥测、崩溃上传、广告请求、社交 SDK、CloudKit、EAS OTA、远程 Push 或远程配置。
- 非 HTTPS Base URL 在发请求前被拒绝。
- 食品数据包按台湾、USDA Foundation、USDA SR Legacy 分包或不可混淆分区；用户自建数据永远不自动进入官方签名包。

### 5.2 AI

- 必须由用户主动触发；未配置、离线、超时、401/403、429、取消或不合约响应均可恢复到手工路径。
- API key 和数据库密钥仅存 Keychain；不进入数据库、日志、工作台、备份或错误报告。
- D-014 只批准营养标签照片逐次预览；餐食照片、纯文本和趋势摘要是否同样逐次预览由 UXD-13/D-033 决定。
- 对任何第三方 AI 载荷，界面必须说明实际 Provider、发送数据和用途并取得显式许可；具体逐次确认频率仍由 UXD-13/D-033 决定，不能把“点击发送”自动解释为已满足 Apple 审核要求。
- AI 结果在用户检查并明确保存前只存在于隔离草稿/暂存，业务数据库零写入。
- AI 输出是可编辑候选，用户确认值优先；不自动覆盖来源库、目标或历史记录。

### 5.3 数据与备份

- 业务数据使用 SQLCipher；数据库密钥放 Keychain。
- D-006 的备份必须加密，不包含 API key 或数据库密钥。
- 导入先在 staging 完成格式、版本、完整性和口令校验；任何失败保持现有数据库零变化；恢复方式在 Owner 批准后原子提交。
- 食品数据包先验签、校验哈希/许可/schema，再原子切换；失败保持当前包。
- 台湾包的 App 来源页、manifest 与 NOTICE 必须通过显名 golden test；USDA 境外再分发在 D-052 获 Owner 处理前保持发布阻断。
- 删除全部本地数据需要取消通知并清除 DB/WAL/SHM、媒体、缩略图、AI 输入/响应暂存、导入 staging、App Group 快照、应用内日志和 Keychain。App 外部 Files 备份不在 App 控制范围。
- 明文 JSON/CSV 可读导出是 D-035 candidate，不属于已批准范围。

## 6. 范围外与证据缺口

九组公开缺口的权威清单见 `docs/01-research/public-evidence-gaps.md`。行级证据为 37 `confirmed`、24 `cross-source`、5 `pending`；九组主题不能与行级状态相加。它们只能有以下处置：

1. 仅研究，不进 UI；
2. 作为 `Nuttie-required` 本地闭环候选，并明确非竞品事实；
3. 只保留能力类别，默认值、算法、规则等待 Owner 决策。

任何文档不得使用“待实现竞品功能”描述 `pending`，也不得使用“竞品同款”描述 Nuttie 自行设计的加密备份、本地搜索、自建食品、CRUD 或 AI 纠错。
